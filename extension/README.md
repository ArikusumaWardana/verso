# Extension Verso

1. Buka `chrome://extensions` dan aktifkan **Developer mode**.
2. Pilih **Load unpacked**, lalu pilih folder `extension` ini.
3. Buka popup Verso dan isi alamat aplikasi, misalnya `http://localhost:3000`.
4. Masuk ke Verso lewat browser yang sama. Setelah itu tombol **Simpan tab ini** memakai sesi tersebut.

Untuk deployment, ganti alamat server dari popup. Izin akses hanya diminta untuk origin yang dipilih.
